Get started

From install to launch, in three steps.#

Opaline is set up entirely in the Shopify theme editor. No code, and every change previews before it goes live.

  1. 01

    Install#

    Add Opaline from the Theme Store and try it on your own products before you buy.

    Install Opaline
  2. 02

    Shape#

    Set your colors and fonts, then compose each page from 48 sections and their blocks.

    Use the theme editor
  3. 03

    Launch#

    Check your pages on desktop and mobile with our checklist, then publish.

    Before you go live
