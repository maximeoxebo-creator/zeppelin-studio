Mobile layouts

Many Opaline sections can be tuned for phones without touching the desktop layout.

How mobile settings work#

Mobile size settings multiply the desktop size: 100% keeps the desktop size, higher enlarges, lower shrinks — on phones only. Set the desktop first, then switch the editor preview to mobile and adjust.

SectionMobile settings
Image / video bannerImage (mobile), eyebrow, heading and text sizes, button scale.
Full-screen heroMobile image, and whether the video plays on mobile.
Statement with imagesSentence size and line spacing on mobile.
Floating showcasePosition and width of each image on mobile.
Multiple columnsColumns on mobile, and a swipeable row.
Product gridColumns, title sizes and breadcrumbs on mobile.
TestimonialsCarousel on mobile, columns on mobile.
HeaderPadding on mobile.
✦
Tip

On phones, product galleries become swipeable carousels, and the quick view panel rises from the bottom of the screen.
