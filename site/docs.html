Welcome to Opaline

Opaline is an editorial Shopify theme built around large photography, fine serif headings and liquid glass. This documentation explains how to install it, set it up and use each of its sections.

How this documentation is organized#

PartWhat you will find
Get startedInstalling Opaline, the theme editor, updates, and a checklist before you open your store.
GuidesStep-by-step explanations of the features that span several sections: the product page, quick view, color swatches, the mega menu, alternate templates, liquid glass, mobile layouts and languages.
Theme settingsEvery store-wide setting: logo, colors, typography, layout, product cards, animations and social media.
Sections48 pages, one per section, each with screenshots on desktop and mobile, how to add it, and a table of every setting and block.
HelpFrequently asked questions, what changed in each version, and how to reach us.

Find a setting quickly#

Press ⌘ K (or Ctrl K on Windows), or click Search the docs at the top of the page. The search covers every page, section and setting name.

Before you start#

  1. Add your products, collections and menus in the Shopify admin first. Many sections show your real content and are easier to set up once it exists.
  2. Duplicate the theme before larger changes, from Online Store > Themes > … > Duplicate. The copy lets you return to a working version at any time.
  3. Preview every change on mobile as well as desktop, using the device icons at the top of the theme editor.
